# Sales Crediting Platform — AI-Integrated Data Pipeline

A working prototype demonstrating an end-to-end Incentive Compensation
data platform: ETL ingestion from multiple source systems, business-rule
driven credit-split logic, a data quality/reconciliation framework, and
a GenAI layer that generates root-cause hypotheses and stakeholder-ready
narratives from verified numbers — not hallucinated ones.

Built to demonstrate the SQL/Python/data-engineering + practical AI
application skill set needed for pharma commercial operations and
Incentive Compensation roles.
